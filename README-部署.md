# 撸货记账 · 部署与使用

一个单页应用（PWA），手机 iPhone / 安卓、电脑浏览器都能用，两端记同一本账实时同步。
同步协议与「五行理财」（www0706.netlify.app）完全同源：复用其 Cloudflare Worker 存储，
按独立身份隔离，撸货账本和理财数据互不可见。

## 首次使用（每台设备）

1. 打开上面的网址
2. iPhone：Safari 分享 → **添加到主屏幕**，之后从桌面图标进，就是全屏 App
3. 手机和电脑各生成自己的同步码（设置页可见），把一端的码粘到另一端 → 两端共用同一本账

## 两台设备怎么共用一本账

- 设备 A：右上角 设置 → 我的同步码 → 复制
- 设备 B：设置 → 导入另一台的同步码 → 粘贴 → 导入并配对
- 之后任何一端改动都会自动推到云端，另一端下次打开自动拉取（改动期间也在页面上则会即时同步）
- 换新手机 / 清了浏览器数据：用同步码重新配对一次，账本从云端回来

## 日常记法（v4 简化版）

- 状态只有三个：**在途**（垫了钱还没结清）/ **已回款** / **自留**。不再区分发货、寄出这些过程。
- 右下角「＋记一单」：必填只有**商品名称 + 垫付金额**，日期默认今天、其余全是一键可选，改完即存。
- 收到钱：点「回款」，金额默认垫付价，有 **+10/+20/+50/+100** 快捷加价和利润实时预览，确认即入账。
- 同款好货：点「再来一单」直接复制一单在途，改个金额就能存。
- 没出掉：点「自留」，回款按 0 计，亏损计入盈亏（编辑里可改回）。
- 0 元购/白嫖单：垫付金额直接填 0，保存时确认一下即可（v9 起支持）。
- 报表页：**月 / 季 / 年** 切换 + ‹ › 翻期，自动生成总结（单数、垫出、收回、净盈亏、环比上期），
  季报/年报带分月盈亏柱状图，另有已结算利润 Top5 商品榜。
- 看板页重点盯「垫付在外未回笼」大字卡（垫出去还没回来的钱）。

## 技术备忘

- 文件：index.html / app.js / sync.js / styles.css / manifest.webmanifest / icon.svg / icon.png
- 同步接口默认 `https://www0706.netlify.app/api/sync`（理财站的 Netlify 反代，已放开 CORS `*`，
  任何静态托管都能直连）；如需换接口，设置页可覆盖（localStorage `luhuo-sync-endpoint-v1`）
- 身份与同步码：`LUHUO1.` 前缀 base64url(userId+secret)，与理财站的 `WUXING2.` 互不相通
- 本地存储键：`luhuo-ledger-data-v1` / `luhuo-ledger-meta-v1` / `luhuo-sync-identity-v1`
- 冲突策略：整包 last-write-wins（与理财站一致），适合单人多端"哪边最后改听哪边"
- 升级代码：改完把 index.html 里的 `?v=N` 加一，强刷缓存
- v4（2026-09-19）：状态简化为在途/已回款/自留（旧六态自动迁移），去掉垫付方式（钱包）维度，
  新增报表页（月/季/年 + 自动总结 + 分月柱状图 + 商品榜）、再来一单、回款快捷加价与利润预览
- iOS 可能因 7 天不用清掉网站数据 → 账本在云端，重新配对即恢复；建议偶尔用设置页导出 JSON 备份
- 测试残留：开发验证时向 Worker 写过一条测试身份的账本（2 笔订单，随机 UUID 隔离），
  无影响，无法也无需清理
