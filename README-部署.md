# 撸货记账 · 部署与使用

一个单页应用（PWA），手机 iPhone / 安卓、电脑浏览器都能用，两端记同一本账实时同步。
同步协议与「五行理财」（www0706.netlify.app）完全同源：复用其 Cloudflare Worker 存储，
按独立身份隔离，撸货账本和理财数据互不可见。

## 首次使用（每台设备）

1. 打开上面的网址
2. iPhone：Safari 分享 → **添加到主屏幕**，之后从桌面图标进，就是全屏 App
3. 手机和电脑各生成自己的同步码（设置页可见），把一端的码粘到另一端 → 两端共用同一本账
4. 底部三个标签切换三页：**看板**（总览）/ **账本**（流水）/ **报表**

## 两台设备怎么共用一本账

- 设备 A：右上角 设置 → 我的同步码 → 复制
- 设备 B：设置 → 导入另一台的同步码 → 粘贴 → 导入并配对
- 之后任何一端改动都会自动推到云端，另一端下次打开自动拉取（改动期间也在页面上则会即时同步）
- 换新手机 / 清了浏览器数据：用同步码重新配对一次，账本从云端回来
- 打开页面若弹一次「**云端有更新的账本，本机还有 N 单是云端没有的**」：点「**确定**」＝把这 N 单并进账本（推荐），
  点「**取消**」＝放弃这几单、改用云端版本。本机的单云端都有（正常同步）时不会弹这个框
- 两端同一时间各改了账：云端只认**最后写进去的那一份**（整包覆盖，不是逐条挑），所以别两端同时记同一批单
- iPhone 有个坑：连续 7 天不用，浏览器可能把本机数据清掉。账本在云端，重新配对就回来；
  偶尔用设置页「**导出 JSON**」留一份更稳

## 日常记法

- 状态只有两个：**在途**（垫了钱还没结清）/ **已回款**。不再区分发货、寄出这些过程。
  - **v21 起「自留」已移除**：货自己留着用就不算生意，直接**把那一单删掉**即可（删除＝这单的钱不再出现在任何汇总里，这是这一取舍的代价，想留痕就给它记个备注）。
  - **旧账本里的「自留」单不会被改写**：升级后它们仍是「自留」，显示成「**自留（旧）**」，金额口径不变（利润＝回款−垫付−邮费，仍计入已结算净盈亏，也不算在途）。它们只能出现在「**全部**」筛选里，用户自己决定删还是留——程序不会替你动这笔账。
  - **账本页上面那一行筛选是三个：在途 / 全部 / 已回款**——下面提到的「筛选行右侧」就是这一行的右端（那里是「批量结算」）。
- 右下角「＋记一单」：必填只有**商品名称 + 垫付金额**，日期默认今天、其余全是一键可选，改完即存。
  - 只收了钱、没有垫付的单（比如给别人开发票收到的钱）也走这里：表单**最上面**切到「**收入**」，见下面《记一笔纯收入（开发票）》。
- 邮费怎么记（**v24 起按这个模型**）：
  - **一起寄的一批只有一个邮费**——那个数记在**批次**上（「批量结算」时填的「本批邮费（整批合计）」），
    随时可以改、可以删（见下面「邮费/回款记错了怎么办」）。成员单上显示的邮费只是它按垫付占比
    **分摊到的份额**，专门为了让每单利润展示得出来；**不会**出现「某一个型号单独记自己的邮费」那种情况
    （用户原话：一起寄件它们肯定是一起处理的，邮费肯定就是算在一起的）。
  - **单寄的单才有自己的邮费**：没进任何批次的单，邮费就是它自己的，记在「邮费」栏（垫付金额旁边）或用「编辑」改。
  - 利润＝回款 − 垫付 − 邮费，不填按 0 算。
  - 「整批金额」是这一批邮费的**唯一权威值**：改的时候各单明细一律按它重摊（不是往各单据上叠），
    所以成员明细之和恒等于整批金额，填 0 就是干净地删掉（不留残值）。
- 收到钱：点「回款」，金额默认垫付价，有 **+10/+20/+50/+100** 快捷加价和利润实时预览，确认即入账。
  金额那一栏旁边有个「**清空**」小按钮，点它＝把这笔回款置成 0。
  - **已经回款的单也能改金额（v26 新增）**：卡片上那个按钮在已回款的单上显示为「**改回款**」
    （位置和样式跟「回款」一样，只有文字换成「改回款」，点开的是同一个弹窗），点开时**金额与回款日期都预填现在记着的值**，
    改完保存即生效——**不必删除重记**。它只改这一条记录自己的回款金额/日期，状态保持「已回款」、
    不产生第二条记录，垫付/邮费/数量/批次归属一个字都不动（利润预览照旧＝回款 − 垫付 − 邮费）。
    - 批内单这样单独改回款后，批次表头会如实提示「**≠ 成员明细合计**」——这是**预期**的（同「单独改一张单的邮费」）：
      批次口径要整批改请走「**改本批邮费**」那个入口（弹窗里邮费、回款两个框都能改）。那句告警后面现在还会补一句自助指引
      「要对齐就点『**改本批邮费**』按当前成员重摊一次」（v27），照着点一下就对齐了。
    - **编辑弹窗里看得到本单回款**（v27）：编辑一条「已回款且有回款」的单时，表单里会出现一行只读提示
      「**本单回款 ¥X · 改金额请用卡片上的「改回款」**」——编辑表单里没有回款栏，想改金额别往「垫付金额」里填。
    - 历史遗留的「**自留（旧）**」单**没有**这个入口（它不是回款语义，保持原样只读）。
- 批量结算（v17 新增，v19 起成批留痕）：整批一起寄、对方回一笔总款时，点账本筛选行右侧的「**批量结算**」：
  勾选本次一起寄出的在途单（默认全选），填**本批邮费（整批合计）**和**对方总回款**，
  系统按各单垫付占比自动分摊到每单，并把勾选的单子置为「已回款」。
  回款还没到就把总回款**留空**，先只分摊邮费、单子保持「在途」，等对方回款了再对这批单跑一次批量结算补回款。
- 批次（v19）：结算过的这一批会从此绑在一起——
  - **账本页**：同批的单子收在一条「一起寄出 · 日期」表头下面，表头写整批口径（N 单 / 垫付合计 /
      邮费合计 / 回款合计），单张卡片左侧一道青瓷竖条；卡片里也直接看得到这一单摊到的邮费。
  - **再次批量结算**：弹窗里这批的单子归在一个「一起寄 · 日期」分组下，点分组那一行的勾选框
     就能**整批勾选/取消**，不用凭记忆一单单挑；分组上还会写「已分摊邮费 ¥45」，一眼看出这批的
      邮费已经摊过、这次只补回款就行（邮费栏留空）。同一批原班人马再结一次 → 续用原批次；
      只勾一半或混着别的单 → 另起一批。
  - **报表页「邮费统计」**：本期邮费合计，下面按批一行行列出「一起寄 · 日期 · N 单 · 邮费 · 回款」
      以及这一批都是哪些货（商品名），单寄没成批的合并成「单寄（未成批）」一行。
      一行里的金额是**成员明细合计**（这一批各单分摊到的邮费/回款加起来）——也就是这一批真实花掉/收回的钱；
      它**正常情况下恒等于**整批金额（v24 纯重摊），只有在「有人事后单独改过某一单」或历史数据的情况下
      两者才会不同，那时行里会补一句「**整批录的是 邮费 ¥X，与成员合计不同（有单被单独改过）**」
      （两个数各自是谁写在明面上，只说明、不改数）。
  - **退出本批（v20，v23 起连钱一起扣）**：结错批了，就在那张单的卡片上点「**退出本批**」，它从此不再和这一批绑在一起。
      整批已经分摊到它头上的邮费/回款**留在它自己身上**照旧算利润（只解绑、不改它的钱）；但它从这一批带走的份额
      会从**还留在批里那几单**的整批口径里扣掉，整批录入值因此恒等于「当前成员实际分摊之和」；
      如果退出后这一批只剩 1 单，那 1 单也一并退出批次（不留「一个人」的批次）。只剩 1 单的批次不再显示「一起寄出」表头。
      （v22 及以前不扣，于是退出后表头会一直挂一句「整批口径仍含它们」式的假漂移，把真正的金额告警顶掉。）
  - **口径怎么看（v21 定稿，v24 起整批与明细恒等）**：**统计只认单子上真实记的邮费/回款**，批次只决定分组与归期：
      - 批次表头一行写的是**整批**口径（标着「整批：」）——v24 起它同时也是这一批的**权威值**
        （各处明细都按它重摊），与成员明细之和恒等；
      - 成员卡片上写的是**这一单分摊到**的明细，报表/看板的邮费都按各单明细汇总：
        「本期邮费合计 ＝ 各批成员邮费之和 ＋ 单寄邮费之和」，恒等于这一期所有单子上记的邮费总和。
        （v20 之前是按整批录入值算的，于是有人「退出本批」时那单的分摊额会被重复计一次——
        v21 全部改成明细口径后这个毛病消失。）
      - 筛选把一批切开时，表头会补一行「本页只显示其中 N 单，另有 M 单被筛选隐藏」；
      - **有人点过「退出本批」或删过批内的单**：表头补一句陈述「**本批已有 N 单不在其中（退出或删除）**」
        （灰蓝，是陈述不是告警）。措辞刻意中性：`batchCount` 只记得到人数，分不出那单是退出还是被删除。
        **退出**那条路 v23 起会把退出者带走的份额从剩余成员的整批口径里扣掉（见上面「退出本批」），
        所以扣完就合得上、不会有后面的「≠」；**删单**那条路不扣（删除＝那一单整笔不再存在，
        整批录入值保持原样，下面的「≠」会如实报出来）。
      - **金额对账任何时候都跑（v22 修，v23 起含义更准）**：表头显示的两项（邮费/回款）只要与成员明细合不上，就标
        「**≠ 成员明细合计 …，与整批口径不同**」（红棕告警色，只提示不改钱）——**与人数有没有变无关**，
        可以和上面那句陈述**同时**出现。退出者的份额会被扣掉（v23 起），所以这句告警基本只在
        「有人事后单独改过某一单的金额」或「删过批内的单」时出现，
        看到它就说明整批值与成员明细**真的**分叉了（v21 会在人数变少时跳过对账；v22 修了这点）。
        改法：在批次表头或那张单卡片上点「**改本批邮费**」，把整批金额重新填一次，明细就都对齐了。
      - 结算时会把**这一批当时结了几单**记在每张单上，上面那句陈述里的人数就是照它报的；
        有人退出后它不再改写（剩下的人还带着旧的人数），原班人马再结一次时才会被改写成新的单数。
- 同款好货：点「再来一单」打开记单表单并**预填原单**（商品/数量/垫付/邮费/渠道/备注），
  日期自动今天、状态在途、回款清空，改一改保存即新建。
- 没出掉：v21 起**直接删掉那一单**（「自留」状态已移除）；老账本里已有的「自留（旧）」单子想删也是点「删除」。
- 0 元购/白嫖单：垫付金额直接填 0，保存时确认一下即可（v9 起支持）。
- 主题：v14 起定稿「青瓷薄荷」浅色玻璃风（绿松石 #14b8a6/#2dd4bf，固定浅色，手机开深色模式也用浅色）。
- 报表页：**月 / 季 / 年** 切换 + ‹ › 翻期，自动生成总结（单数、垫出、收回、净盈亏、环比上期），
  季报/年报带分月盈亏柱状图；页面上的图共三张（「**现金流走势**」「**净盈亏分布**」「**商品利润占比**」），另有一张「**邮费统计**」卡与已结算利润 Top5 的「**商品榜**」。
- 看板页重点盯「垫付在外未回笼」大字卡（垫出去还没回来的钱）；「本月垫出」格下另有一行本月邮费，
  大字卡的提示行也会补一句「**另有邮费 ¥X**」（在途单自己记的邮费合计；那个大字本身只算垫付，不包含邮费）。
  - **这两行「另有邮费」不是一个数**：大字卡那行是**还在途的那些单**记的邮费合计，「本月垫出」下面那行是**本月**记掉的邮费——两者本来就不该相等。
- **口径（v27 统一后的写法）**：**一笔钱算不算收入，只看「回款金额填了没有」（非空即计入），与状态无关**；
  归期看**回款日期**（没有回款日期时只进「累计回款」，不落进任何一个具体月份）。
  所以看板的「累计回款/本月回款」与报表的「回款」永远是同一个答案——v27 之前看板按「回款非空」、
  报表按「已结算且有回款日期」，一条「已回款」的单被编辑成「在途」（回款字段留着）后两处会给出不同的数。
  利润跟着收入一起认（认了这笔收入就认这笔盈亏），垫付/邮费照旧按各自的下单日期/批次日期归期。

## 报单（v28 新增：寄出一批后发给收货商）

寄出之后要给收货商报「型号 / 颜色 / 数量」时用这个——**点一下就整理好并复制到剪贴板，直接去微信粘贴**。

- **两个入口**：① 账本页「一起寄出 · 日期」那条**批次表头**上的「**报单**」→ 报这一批的全部成员；
  ② 筛选行右边的「**报单**」→ 报**当前筛选下看得见的那些单**（所见即所报，范围会写在面板标题后面）。
- **点一下＝已经复制好了**：面板打开的同时剪贴板里就有内容（提示报「已复制报单 · N 件 / M 种」）。
  面板是用来核对与微调的，不看它也能直接去微信粘。
- **文本长这样**（照你发给收货商的那种消息）：

  ```
  9.21 待结
  狗屁王二代金刚黑 ×5
  狗屁王 4 朱雀黑 ×2
  狗屁王 3 黑色 ×1
  ```

  首行「月.日 待结」——成批报用**这一批自己的日期**，工具条入口用今天；下面**一行一件**，
  **每行行尾都带数量**，没有合计行。想加称呼/单号、想改数量的写法，直接在面板的文本框里改，
  再点一次「复制报单」：**复制出去的就是框里现在的文字**。
- **同名的并成一行、数量相加**：同一件货记过几单（例如从不同店买的同款）会合成一行 ×N。
  「件数」按每条单自己填的**数量**相加，**不是订单条数**。
- **写法不一致也会并**：`红米 Note 13 白` 与 `红米Note13白`（空格、大小写、全角空格不同）算同一组，
  面板里会写一句「已把同物异写并成一组：…」让你看见它并了什么；显示用你**最早那条单的原始写法**。
  `白` 与 `白色` **不会**自动合并——宁可多一行让你手动删，也不去猜颜色（猜错等于把两种货报成一种）。
- **要剔掉某一单、或一批拆两次报**：在面板的清单里取消勾选那一单（默认全勾），文本立刻重算。
- **面板是只读的**：勾选、改文案、复制都不动账本、不进同步包，关掉即丢；账本内容要改请去编辑那一单。
  另外收入单（开发票）如果落在报单范围里也会被当成一行报出去——它没被特殊处理，用不上就取消勾选。

## 邮费/回款记错了怎么办（v23 新增，v24 补全入口）

按下面几种情形对号入座（整批部分的回款同理，把「邮费」换成「回款」即可）：

| 你的情况 | 入口 | 怎么做 |
| --- | --- | --- |
| **单寄的一单**（没成批）记错了 | 那张单卡片上的「**编辑**」 | 改「邮费」栏 → 保存；**留空就是删掉它**（按 0 算），旁边有个「**清空**」小按钮一键置空。邮费栏本来就不是必填 |
| **就这一单收到的钱记错了**（含纯收入单） | 那张单卡片上的「**改回款**」 | 点开时金额与回款日期都预填现在记着的值 → 改成正确的数字 → 确认。只改这一单，不会多出一条记录（旧「自留（旧）」单没有这个入口） |
| **整批一起寄的那一批**记错了 | ① 账本页那条「一起寄出 · 日期」表头上的「**改本批邮费**」；② **同一批里每张单的卡片上**也有同一个按钮 | 点开弹窗已经替你勾好这一批全部成员 → 填新数字 → 结算。寄出去后才发现邮费变了，就是这条 |
| **想彻底删掉这一批的邮费** | 同上 | 同上，但新数字填 **0** = 删掉这一批的邮费：成员明细也一并归 0、表头不再显示邮费、报表与看板同步归零 |
| **不确定那笔钱花在哪** | 报表页「**邮费统计**」卡 | 本期邮费合计下面按批一行行列着这一批**都是哪些货**（商品名）与金额，单寄的合并成「单寄（未成批）」一行 |

**入口在哪（一句话）**：除了「一起寄出 · 日期」那条**批次表头**右侧，**每张批内单的卡片上**（「退出本批」旁边）
也有「**改本批邮费**」——两者点开的是同一个弹窗。v23 只有表头有，于是①一批只剩 1 单时不显示表头、
②筛选把那一批藏起来时表头不在页面上——这两种情形下都点不到，v24 补上了。
（另外：批内单在「编辑」里也能单独改它的邮费，那只是改这一单的展示值，会和整批金额不一致，
表头会用「≠ 成员明细合计」如实提示——要改这一批就请走上面的入口。）

三条规矩（v24 起弹窗里就这么三条，**没有「覆盖 / 追加」要选**）：

- **填数字＝把这一批改成这个数**：整批金额是这一批邮费的**唯一权威值**，成员明细按各单垫付占比
  重新分摊（**不是**往原来记的数上叠加，也不会保留什么「这一单自己记过的邮费」——一起寄的一批只有一笔邮费）。
  同一个数字填两遍，结果一样（幂等）。
- **留空＝一个字不动**。弹窗里两个框（本批邮费 / 对方总回款）谁留空谁不动，所以
  「先只摊邮费、回款到了再补一趟」照旧：第二趟只填回款、**邮费留空**，已经记好的邮费不会被清掉。
- **填 0＝删掉这一笔**：邮费填 0 → 这一批的邮费清零（成员明细一起归 0、报表/看板同步归零）；
  回款填 0 同理（单子仍是「已回款」，收没收到钱是另一回事，要改状态去「编辑」里改）。
- 新建批次（还没有旧批）不显示那行说明，直接按新批次写入。

## 记一笔纯收入（开发票）（v25 新增）

「只收了钱、没有垫付、没有成本」的生意（给别人**开发票**收到的钱就是典型）不必再假装成一单货——
这一节只管**把到账的钱记进总账**，发票怎么开、税怎么算，它一概不做：

- **怎么进**：右下角「＋记一单」→ 表单**最上面**多了一条「**货单 / 收入**」的类型切换 → 点「**收入**」。
- **填什么**：只剩 **名称 / 金额 / 日期 / 渠道 / 备注** 五项（默认名与默认渠道都预填「**开发票**」，
  日期默认今天，渠道不是必填）。垫付/邮费/数量/状态那四项会**整格收起来**（不是置灰）——
  它们不参与校验也不参与提交，所以不用管。
  - 名称留空、金额留空、金额为负 → 拒绝保存并提示；**金额填 0 是合法的**（一笔 0 元收入），
    与「留空」不是一回事。
  - 收入单保存**不会**弹那个「垫付金额为 0」的确认框——它只服务**货单路径**，货单垫付 0 时照旧会弹。
    （v26 起那句话改成中性措辞：「**这一单垫付金额为 0（白嫖单或纯收入单），确认保存吗？**」——
    因为**编辑**一条已有的收入单会按货单路径回显、垫付恒为 0，那次确认是必然要出现的，
    老文案「确认这是 0 元购/白嫖的单子吗」在那条路上读不通。刻意保留这次点击、只改措辞。）
  - 切回「货单」时字段原样恢复，刚才填过的值都还在（隐藏只是收起来，不会清掉）。
- **落到哪些字段**（一句话：**不落任何新字段**）：金额写进 **回款金额**（`income`），日期同时写进
  **下单日期**（`date`）与**回款日期**（`incomeDate`）——你只填一个日期，它既是发生日也是到账日；
  状态直接是「**已回款**」、垫付与邮费都是 **0**、数量 1。所以这条记录在账本、同步、备份里与一单普通
  货单**完全同形**，老账本一行都不用迁移，也不存在「类型」这种字段。
- **在报表里怎么看**：**没有单独的「收入」分块、列或图例**——这笔钱直接并进现有的
  **总收入（回款）与净利润**（净利润 = 逐单「回款 − 垫付 − 邮费」求和，收入单的贡献恰好等于它的金额），
  **成本侧（垫付/邮费）一分都不会多**，按你填的那个日期归期（跨月就落在所选的月份）。
- **想看都有哪些收入**：账本页「**全部**」/「**已回款**」里能看到这些卡片（垫付 ¥0、邮费 ¥0、
  利润 = 那一笔金额）；报表「**商品榜**」里会出现一条以你填的名称（默认「开发票」）为名的条目。
  「再来一单」可以拿它当模板再记一笔。
- **改错了怎么办**：点卡片上的「**编辑**」改名称/日期/渠道/备注（打开时按普通货单形态回显：
  垫付 0 / 邮费 0 / 数量 1 / 已回款，直接保存不会丢金额）。**金额走卡片上的「改回款」**（v26）：
  点开时金额与回款日期都预填现在记着的值，改完保存**只改这一条的回款金额与回款日期**——
  不新增记录、不动垫付/邮费/数量/批次，**不必删除重记**。
  （顺带修掉一个老毛病：垫付为 0 的单以前点开「编辑」时垫付栏是**空白**，而它带必填 →
  什么都不改点保存会像卡住一样没反应；v25 起 0 就写成 0，直接保存能过。）

  （只在 <0 时动手，0 与正数原样保留）。表单本来就拦负数（`min="0"`），能带进负值的只有**导入 JSON**

  卡片上却照原样显示「邮费 −¥3」。`income` **不在**收敛范围内（负回款在各处口径一致，没有这种矛盾）。

  **摊到多少**，与 `batchId/batchDate/batchFee/batchIncome/batchCount` 一样冗余在每张单上。
